# Ce reușește capitolul

Capitolul transformă o expresie care ar putea suna vag contemporan — „inconștient familial” — într-o construcție doctrinară precisă și istorică.

Mișcarea reușită este:

`posibilități de destin -> al treilea inconștient -> revendicări ancestrale -> genă latentă / Konduktor -> genotropism -> Genverwandtschaft -> arbore genotropic -> tensiunea gene/pulsiune -> Deri/Mélon -> limită -> cap. 4`.

---

# Propozițiile de axă

Două formule proprii ale manualului pot rămâne:

> **Ceea ce nu se manifestă ca trăsătură ar putea, după Szondi, să se manifeste ca alegere.**

și

> **A înțelege o doctrină nu înseamnă a o valida.**

Prima comprimă ipoteza genotropică; a doua fixează poziția epistemică a manualului. Niciuna nu este citat Szondi.

---

# Câștig doctrinar

Capitolul stabilește o separare care trebuie protejată în restul cărții:

- `familiäres Unbewußtes` = strat teoretic;
- `Ahnenansprüche/Ahnenfiguren` = conținutul dinamic conceptualizat;
- `Genotropismus` = mecanism biologic postulat;
- `Wahlsprache`, genealogia și testul = căi de investigare/manifestare.

Această separare împiedică atât metaforizarea vagă, cât și biologizarea simplistă.

---

# Vocea

DRAFT v2 este mai dens decât cap. 1 și mai concret decât cap. 2. Această diferență este utilă. Arborele genealogic genotropic funcționează drept centru concret al capitolului, iar genetica este introdusă numai după ce cititorul știe ce problemă încearcă să rezolve.

Textul păstrează terminologia istorică fără a o folosi ca verdict contemporan și nu alunecă într-o respingere polemică a lui Szondi.
