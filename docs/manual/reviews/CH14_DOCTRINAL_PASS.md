## Delimitări protejate

- `!` este marcaj formal de `Überdruck` / `Quantumspannung`, nu severitate clinică;
- `Quantumspannung` privește o reacție factorială dintr-un profil;
- `Tendenzspannungsgrad (TspG)` este măsură de serie și se calculează din `Σ0 + Σ±` pentru factor;
- TspG apare în capitol numai pentru anti-confuzie, fără calcul sau aparat de serie;
- `0` liber și `ø` forțat nu sunt fuzionate; `ø` rămâne forward hold pentru complement/serie.
