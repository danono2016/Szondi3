# CH32 OUTLINE — Regula de bază: niciun semn nu se citește singur

**Status:** OUTLINE  
**Bază:** `CH32_RESEARCH.md` — research 10/10 + bounded deep corpus pass complete.

## Întrebarea cognitivă

Ce trebuie să se schimbe în mintea cititorului înainte de prima lectură reală de profil?

## Achiziția centrală

Semnul factorial nu este o propoziție despre persoană. El este o reacție situată într-o configurație. Sensul se precizează prin relații succesive, iar interpretarea devine eronată când una dintre trepte este sărită.

## Mișcarea capitolului

### 1. Reflexul greșit

Pornește din tentația firească: după ce cititorul a învățat opt factori și semnele `+ − ± 0`, pare că poate combina cele două ca într-un dicționar.

Fisura: dacă ar funcționa astfel, întregul aparat al vectorilor, profilelor și seriilor ar fi inutil.

### 2. Semnul nu spune nimic singur

Clarifică diferența:

- `+` singur nu este un sens psihologic;
- `+h`, `+k`, `+d` nu sunt variații ale aceleiași trăsături;
- semnul notează forma reacției factorului.

### 3. Reacția are un vecin obligatoriu

Introdu factorul partener ca prima contextualizare, fără a preda încă metoda cap. 34.

Idee: un factor intră în profil deja într-un vector; reacția lui schimbă și este schimbată de reacția partenerului.

### 4. Configurația este mai mare decât suma semnelor

Folosește exemplul canonic din `Triebpathologie II`: numai combinația specială, nu reacția izolată, poate susține o anumită direcție de interpretare.

Nu dezvolta catatonia; exemplul este despre logică, nu despre sindrom.

### 5. `0` ca probă de stres pentru dicționar

Un singur exemplu scurt: `0` poate avea sensuri diferite în funcție de factor și configurație. Nu reface cap. 13.

Aici poate intra Deri, explicit atribuită: sensul reacției „open/drained” depinde de profilul total și de seria totală.

### 6. Scara contextului

Formulează pentru prima dată scara care va guverna Partea VI:

`reacție -> factor partener -> Vektorbild -> relația dintre vectori -> profil -> complement -> serie`

Dar marchează că ultimele trepte vor fi dezvoltate ulterior; cap. 32 instalează doar ordinea.

### 7. Context testologic ≠ context clinic

Foarte scurt. În această parte, „context” înseamnă întâi structura internă a testului. Trecerea la clinică este un alt prag.

`profil -> ipoteză testologică`, nu diagnostic.

### 8. Final

Nu recapitula întreaga scară. Închide prin schimbarea de reflex:

cititorul nu mai întreabă „ce înseamnă +k?”, ci „ce face +k aici?”.

Această schimbare deschide cap. 33: pentru a răspunde „ce face aici?”, trebuie citită corect reacția factorială însăși — semn, încărcare, context imediat.

Capitol metodic, dar nu procedural. Trebuie să producă o schimbare de gândire înainte de tehnică.

Mișcare dorită:

`dicționar tentant -> contradicția cu sistemul -> reacția ca poziție -> combinația ca sens -> scara contextului -> noul reflex de lectură`.
