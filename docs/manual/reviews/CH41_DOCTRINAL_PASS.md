## Nucleul de control

Auditul trebuie să verifice direct:

- `TspG = Σ(0 + ±)` pe factor, în serie;
- `TspG ≠ Quantumspannung` și `!` nu intră în sumă;
- `faktorieller TspG`, nu `täglicher TspG`, este baza pentru `TspD`;
- `TspD = TspG mai mare − TspG mai mic` intravectorial;
- indexul vectorului aparține factorului cu `TspG` mai mic;
- `TspD = 0` nu identifică un singur `Vektorbild`;
- `Latenzgrad / Latenzgröße` și `Latenzproportionen` sunt păstrate în rangul și terminologia sursei;
- egalitățile rămân egalități, fără tie-break inventat;
- `Triebklasse/Unterklasse`, `Triebformel` și `TspQu` rămân în capitolele 42–44.

## Audit focus — CH41-SHORT-01

`sume factoriale 0 + ± -> Tabelle 13 -> TspG factorial convertit -> TspD -> Latenzproportionen`.

Motivul este material: lookup-ul `Tabelle 13` nu este liniar, iar schimbarea ordinii operațiilor poate schimba rezultatul numeric.
