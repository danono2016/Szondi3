- fiecare profil se interpretează separat, `in seiner Ganzheit`;
- `in seiner Ganzheit` ≠ exhaustivitate;

- 8–10 nu este prag universal pentru toate operațiile seriale;
- scara constanței `Trieblinnäus` este **3–8** și culminează la 8 cu `Konstanz des gesamten Trieblinnäus`;
- **9 nu este prag nou de constanță**;
- `Tabelle 13` convertește seriile de **3–9** profile la baza **10**;

- seria nu este media profilelor;
