**PASS.** Sunt păstrate corect:

- `k+ = Introjektion`;

**PASS.** `Sch(+,−) = Introprojektion` este formulată doctrinar corect: Lehrbuch spune explicit că tendințele proiectate în afară (`−p`) sunt incorporare de către propriul Eu (`+k`). `Sch(−,+) = negierte Inflation / Hemmung` este de asemenea conform.
