**Statut:** CONSOLIDATED DRAFT v1.0

> Acest document fixează arhitectura pedagogică rezultată din audit. Nu înlocuiește cercetarea 10/10 obligatorie pentru fiecare capitol și nu transformă concluziile structurale în doctrină.

## Principiul de construcție

Cartea urmează traseul:

`alegere -> sistem pulsional -> administrare -> factori/vectori -> Eu -> lectură de profil -> serie -> aparat formal -> clinică -> destin -> terapie -> cabinet`

Fiecare capitol trebuie să rezolve o singură problemă cognitivă principală. Un concept intră în carte numai când cititorul are deja instrumentele necesare pentru a nu-l înțelege greșit.

Patru praguri pedagogice rămân obligatorii:

1. după cap. 14, cititorul poate **construi corect un profil**, fără a-l interpreta clinic;
2. după cap. 31, cititorul înțelege **aparatul conceptual al factorilor, vectorilor și Eului**;
3. după cap. 45, cititorul poate **organiza și calcula formal o serie** și știe unde se termină calculul;
4. după cap. 63, cititorul poate **construi o formulare clinică Szondi trasabilă**, fără a confunda testul cu diagnosticul sau cu sinteza clinicianului.

# Regula de înghețare a arhitecturii

Arhitectura poate fi schimbată ulterior numai dacă cercetarea 10/10 a unui capitol demonstrează una dintre următoarele situații:

1. capitolul nu are suport doctrinar suficient;
2. o distincție esențială a fost comprimată până la falsificare;
3. două capitole sunt demonstrabil redundante;
4. o temă indispensabilă pentru traseul cititorului nu are încă un loc;
5. o schimbare este necesară pentru fidelitate, nu doar pentru preferință stilistică.

În lipsa uneia dintre aceste situații, această arhitectură este baza de lucru pentru manual.
