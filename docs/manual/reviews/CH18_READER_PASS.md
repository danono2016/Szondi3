# Capitolul 18 — Reader pass

**Capitol:** Factorul e — afect brut, Cain și bariera etică  
**Verdict:** PASS  
**Statut rezultat:** STABLE DRAFT

## Ce funcționează

Capitolul are o problemă intelectuală clară și o rezolvă progresiv: cum poate același factor să lege afectele brute, Cain, Abel și bariera etică fără să devină nici „factorul furiei”, nici un test moral.

Deschiderea este bună pentru că pornește din disonanța reală a vocabularului (`epileptiform`, Cain, dreptate, conștiință) și produce nevoia explicației, nu doar o listă de definiții.

Secțiunea **„Afectele nu sunt pulsiuni”** trebuie păstrată aproape exact. Ea previne cea mai probabilă eroare de lectură înainte ca restul capitolului să înceapă și delimitează bine `e` de o psihologie generică a emoțiilor.

Mișcarea `afect brut -> acumulare/descărcare -> Cain -> Abel -> barieră etică -> ambivalență -> zero` este inteligibilă și are progresie. Formula **„Mose ist der abelisierte Kain”** funcționează ca punct de condensare și nu apare ca ornament.

Diferența `e` versus `s` este bine plasată. Cititorul tocmai vine din factorul Thanatos, deci această recapitulare rezolvă o confuzie reală, nu repetă administrativ capitolul precedent.

Finalul păstrează limita pedagogică: factorul `e` este înțeles, dar vectorul P nu este încă predat. Astfel, `hy` devine necesar în loc să fie doar următorul element al listei.

## Dozaj

Capitolul este dens, dar densitatea este justificată de noutatea conceptuală. Nu există motiv pentru o scurtare generală.

Pasajele despre `Tendenz zum Guten/Bösen`, Cain/Abel și conștiință riscă prin natura lor să sune moralizator, dar textul introduce suficient de repede limitele: reacția factorială nu certifică bunătatea, răutatea, violența sau moralitatea persoanei.

Secțiunea despre Überdruck este suficient de scurtă și nu reia inutil cap. 14; folosește doar aparatul deja învățat pentru a arăta de ce intensificarea nu este diagnostic.

## Claritate

- `Kaintendenz` și `Abeltendenz` devin inteligibile prin dinamica afectului, nu prin etichete biblice.
- `ethische Gewissensschranke` este explicată concret ca limită între afect și acțiune.
- `e±` este diferențiat bine de indecizia banală prin `Gewissenszweifel` / `gesunder ethischer Kampf`.
- `e0` aduce informație nouă față de regula generală a zero-ului: poate urma destine foarte diferite ale descărcării, inclusiv reparația.

## Ce NU trebuie schimbat fără o problemă nouă

- nu simplifica `e` la „reglare emoțională”;
- nu elimina vocabularul Cain/Abel doar pentru că este istoric sau neobișnuit;
- nu transforma `e+` într-un pol pozitiv valoric și `e−` într-un pol negativ clinic;
- nu muta aici interpretarea completă `e–hy`;
- nu adăuga cazuri clinice severe doar pentru ilustrare.

## Verdict

DRAFT-ul este suficient de adevărat, clar, viu și delimitat pentru progresie. Nu există o problemă concretă care să justifice un nou pass înainte de continuarea cărții.

**CH18 -> STABLE DRAFT.**

Următorul capitol autorizat este cap. 19, factorul `hy`.
