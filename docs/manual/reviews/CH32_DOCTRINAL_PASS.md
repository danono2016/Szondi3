1. **Semnul formal nu este sens psihologic autonom.**

Această regulă este consonantă cu arhitectura `Vektorbild` din Lehrbuch și cu practica interpretativă a corpusului primar.

Draftul o folosește numai ca demonstrație a imposibilității dicționarului, fără a reface taxonomia reacțiilor.

6. **Deri este atribuită explicit.**
