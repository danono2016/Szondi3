## Întrebarea cognitivă

**Cum transformă Szondi ordinea celor patru `Latenzgrade` într-o `Triebklasse` și `Unterklasse`, cum se identifică `Wurzelfaktor`-ul și cum se separă rangul relativ al clasei de pragul absolut `Triebgefahr / Triebventil`?**

## Teza capitolului

> **`Triebklasse` este construită din rangul relativ al latențelor; `Triebgefahr` și `Triebventil` folosesc, separat, mărimea absolută a `Latenzgröße` pe scara canonică a unei `Zehnerserie`.**

Lanțul de control trebuie să rămână vizibil:

`Latenzproportionen -> maxim relativ -> Haupttriebklasse -> Wurzelfaktor + direcție -> Unterklasse`

și, separat:

`Latenzgröße 5–10 -> Triebgefahr`  
`Latenzgröße 0–4 -> Triebventil`.

Formula epistemică de control:

> **clasa organizează formal latențele unei serii; nu stabilește singură un diagnostic și nu fixează persoana într-un tip imuabil.**

# Mișcarea capitolului

## 1. Deschidere — după proporție vine rangul

Deschiderea pornește direct din cap. 41, fără recalcularea `TspG` sau `TspD`.

Cititorul are deja o proporție de forma:

`Schp− / 10 : Phy− / 6 : Sh+ / 6 : Cd+ / 3`.

Întrebarea nouă nu mai este „cum am obținut aceste valori?”, ci:

> **care dintre ele conduce seria, ce factor latent poartă această poziție și ce statut primesc celelalte valori?**

Trebuie instalată imediat distincția dintre **rang relativ** și **prag absolut**, fiindcă aceasta organizează întregul capitol.

## 2. Prima axă: maximul relativ și `Haupttriebklasse`

Regula se introduce direct:

- ordonăm cele patru `Latenzgrade`;
- valoarea relativ maximă indică vectorul în care latența este cea mai mare;
- factorul deja indexat în notația latenței dă numele clasei.

Exemplu canonic:

`Sh / 13 : Schp / 4 : Cm / 4 : P / 0`

Maximul este `Sh / 13`, deci clasa conducătoare este:

**`Haupttriebklasse Sh`.**

Protecție obligatorie:

> **„maxim relativ” nu înseamnă automat „peste pragul absolut de `Triebgefahr`” decât atunci când mărimea este evaluată pe scara canonică pentru care pragul este documentat.**

## 3. Cele opt `Haupttriebklassen`

Lista trebuie prezentată compact și memorabil:

- S -> `Sh`, `Ss`;
- P -> `Pe`, `Phy`;
- Sch -> `Schk`, `Schp`;
- C -> `Cd`, `Cm`.

Rezultă:

`Sh, Ss, Pe, Phy, Schk, Schp, Cd, Cm`.

Nu dezvoltăm aici conținut clinic pe clase. Capitolul predă mecanica și rangul doctrinar, nu sindromatica.

## 4. De ce factorul din clasă este `Wurzelfaktor`

Legătura cu cap. 41 trebuie făcută fără repetiție:

- în fiecare vector, factorul indexat este cel cu `TspG` mai mic;
- în doctrina lui Szondi, acesta este factorul mai latent / mai puțin descărcat;
- în sistemul claselor primește rang de `Wurzelfaktor`.

Trebuie păstrată diferența dintre:

- **regula operațională:** factorul cu `TspG` mai mic;
- **interpretarea doctrinară:** trebuință latentă, nesatisfăcută, dinamic determinantă;
- **teza genetică istorică:** legătura cu `Konduktornatur`.

Formula de protecție:

> **`Wurzelfaktor` este un termen al doctrinei lui Szondi, nu dovada unei „rădăcini genetice” demonstrată clinic prin test.**

## 5. `Unterklasse`: semnul direcției latente

După identificarea `Haupttriebklasse`, cititorul trebuie să vadă cum apare subclasa.

Regula:

- factorul latent / `Wurzelfaktor` poate avea direcție `+` sau `−`;
- semnul acestei direcții se atașează clasei;
- opt clase x două direcții = **16 `Unterklassen`**.

Lista completă poate fi dată o singură dată:

`Sh+`, `Sh−`, `Ss+`, `Ss−`,  
`Pe+`, `Pe−`, `Phy+`, `Phy−`,  
`Schk+`, `Schk−`, `Schp+`, `Schp−`,  
`Cd+`, `Cd−`, `Cm+`, `Cm−`.

## 6. Ce nu înseamnă semnul `+ / −`

Secțiune scurtă, obligatorie:

- nu este semnul unui `TspD`;
- nu este semnul vectorului ca întreg;
- nu este evaluare morală;
- nu autorizează un dicționar universal `+ = bun`, `− = rău` sau `− = reprimare`.

Apoi se introduce scurt justificarea lui Szondi:

- latență pozitivă: persistența direcției pozitive, uneori cu `Überdruck`, în condițiile unei trebuințe care rămâne nesatisfăcută;
- latență negativă: poate implica `Verdrängung`, dar și `Anpassung` ori `Verzicht`.

Aceasta rămâne **doctrină contextuală despre construirea subclasei**, nu cod interpretativ universal.

## 7. Exemplul complet de trecere la subclasă

Exemplul pedagogic principal:

`Schp− / 10 : Phy− / 6 : Sh+ / 6 : Cd+ / 3`.

Cititorul trebuie să poată extrage fără ezitare:

- maxim relativ = `10`;
- vector = Sch;
- factor latent = `p`;
- direcție = `−`;
- `Haupttriebklasse = Schp`;
- `Unterklasse = Schp−`.

Aceasta este prima închidere practică a axei relative.

## 8. A doua axă: pragul absolut `Gefahr / Ventil`

Abia după ce axa relativă este clară introducem pragul numeric.

Formularea trebuie să păstreze domeniul sursei:

> **pentru o `Zehnerserie`, `Latenzgröße` 5–10 indică `Triebgefahr`, iar 0–4 indică `Triebventil`.**

Vizual:

- `5, 6, 7, 8, 9, 10` -> `Triebgefahr`;
- `0, 1, 2, 3, 4` -> `Triebventil`.

Nu folosim formule aproximative de tip „mare/mic”; pragul este numeric în sursă.

## 9. `Triebgefahr` nu este risc clinic contemporan

Legătură scurtă cu cap. 36:

- aici `Triebgefahr` este produsă formal din mărimea latenței;
- rămâne categorie testologic-doctrinară Szondi;
- nu este scor modern de risc, prognostic de violență sau severitate clinică.

Nu reluăm teoria `Rand / Mitte`.

## 10. `Ventil` înseamnă `Notausgang`, nu „resursă sănătoasă”

Aceasta este una dintre limitele centrale ale capitolului.

Trebuie spus direct:

- `Ventil` = ieșire / canal de descărcare;
- Szondi îl poate lega de `Symptomfaktor`;
- poate fi clinic simptomatic;
- nu se traduce prin `coping`, `resursă`, „reglare adaptativă” sau sănătate.

Formula de control:

> **`Ventil` spune pe unde poate ieși tensiunea; nu spune că ieșirea este sănătoasă.**

## 11. Una, două, trei sau patru `Gefahren`

După pragul absolut, cititorul trebuie să înțeleagă că numărul domeniilor care trec pragul este o a doua informație, distinctă de subclasa conducătoare.

Exemplu:

`Sh+ / 10 : Schp− / 9 : Cm / 2 : P / 1`.

Aici:

- `Sh+ / 10` și `Schp− / 9` sunt `Gefahren`;
- `Cm / 2` și `P / 1` sunt `Ventile`;
- există **două `Gefahren`**;
- clasa conducătoare rămâne dată de maximul relativ.

Concluzie:

> **„care clasă conduce?” și „câte pericole trec pragul?” sunt două întrebări diferite.**

## 12. Când toate valorile sunt sub 5: `Ventil-/Symptomklassen`

Dacă toate patru `Latenzgrößen` sunt `0–4`, intrăm în sistemul târziu al `Ventil-/Symptomklassen`.

Trebuie predată simplificarea din `Lehrbuch` 1972:

- `Biventilklasse` nu mai este evidențiată separat;
- `Triventilklasse`;
- `Quadriventilklasse`.

Nu introducem nomenclatura mai veche ca mecanică principală.

## 13. `Triventilklasse` și `Quadriventilklasse`

Regulile trebuie date mecanic:

- dacă toate valorile sunt sub 5 și amplitudinea `max − min = 3–4` -> **`Triventilklasse`**;
- dacă toate valorile sunt sub 5 și amplitudinea `max − min < 3` -> **`Quadriventilklasse`**.

Pentru localizarea lor în tabele, Szondi folosește valoarea relativ cea mai mare.

Protecție:

> **dacă maximul relativ este egal în două sau mai multe poziții, nu inventăm un tie-break universal.**

Acesta rămâne `CH42-AUDIT-02` pentru control doctrinar extern.

## 14. `Äqualität`: ce rămâne și ce este depășit

Aceasta trebuie să fie secțiunea cronologică principală a capitolului.

Se disting două lucruri:

1. **egalitatea reală dintre `Latenzgrade`** — rămâne și poate fi descrisă ca `Äqualität`;
2. **vechiul sistem de denumire a claselor** `inäqual / biäqual / triäqual / quadriäqual` — este declarat explicit `hinfällig` de `Lehrbuch` 1972.

Formula de control:

> **egalitatea rămâne fapt descriptiv; vechea nomenclatură de clasă bazată pe ea nu mai este mecanica principală a ediției târzii.**

## 15. Deri și sistemul celor 144 de variante

Deri trebuie introdusă numai ca strat istoric/pedagogic:

- explică foarte clar mecanica clasei și a semnului latent;
- descrie însă sistemul vechi cu bi-/tri-/quadri-equality și până la 144 variante;
- acest sistem nu este predat ca forma finală a clasificării după revizia din 1972.

Mélon poate fi menționat mai scurt ca tradiție ulterioară care confirmă sistemul revizuit `Gefahr/Ventil`.

Nici Deri, nici Mélon nu arbitrează asupra sursei primare.

## 16. `Triebklasse` este actuală și mobilă

Această secțiune trebuie să împiedice cea mai periculoasă reificare a capitolului.

Păstrăm tezele târzii:

- `Triebklasse` este **`aktuell`**;
- persoana poate trece dintr-o clasă în alta;
- apartenența este **`relativ umweltlabil`**, nu absolut stabilă.

Consecinție:

> **`Triebklasse` nu este un tip fix de personalitate.**

Această mobilitate trebuie pusă în continuitate cu logica seriei din cap. 38–39, fără reluarea acelor capitole.

## 17. Toate cele patru latențe rămân relevante

Clasa conducătoare nu șterge proporția.

Trebuie spus:

- maximul relativ dă clasa principală;
- minimul arată `Notausgänge / Ventile` mai accesibile;
- valorile intermediare rămân parte din configurație;
- ordinea întregii `Latenzproportion` contează.

Aceasta împiedică transformarea cap. 42 într-un dicționar „primul termen = persoana”.

## 18. Frontiera spre `Triebformel`

Cap. 42 se oprește după localizarea rădăcinilor și a ventilelor la nivelul claselor.

Poate spune:

- `Triebklasse` orientează spre `Wurzelfaktoren`;
- `Triebformel` va individualiza și `Symptomfaktoren / Ventile`.

Nu se predau aici:

- forma fracției;
- numărătorul / numitorul;
- formula abreviată sau completă;
- regulile exacte ale `Triebformel`.

Acestea sunt cap. 43.

## 19. Domeniul sigur al algoritmului: `Zehnerserie`

Aceasta trebuie să fie secțiunea de limită tehnică.

Algoritmul complet sigur al capitolului se predă pentru `Zehnerserie`, deoarece:

- pragul `5/4` este formulat explicit acolo;
- `CH41-SHORT-01` lasă neechivocă doar parțial ordinea conversiei pentru seriile 3–9;
- pentru serii brute >10, research-ul nu a identificat o regulă primară explicită care să universalizeze pragul `5/4` fără ajustare.

Prin urmare:

> **nu transformăm pragul `5/4` într-un cutoff universal independent de lungimea seriei.**

Acesta rămâne `CH42-AUDIT-01`.

## 20. Algoritmul didactic final pentru `Zehnerserie`

La sfârșitul corpului tehnic, cititorul trebuie să poată executa fără ambiguitate:

1. pornește de la cele patru `Latenzgrade` deja construite;
2. păstrează ordinea și egalitățile;
3. maximul relativ -> `Haupttriebklasse`;
4. factorul indexat -> `Wurzelfaktor`;
5. direcția `+ / −` -> `Unterklasse`;
6. separat, fiecare valoare:
   - `>=5` -> `Triebgefahr`;
   - `<=4` -> `Triebventil`;
7. notează numărul de `Gefahren`;
8. dacă toate sunt `<=4`, verifică amplitudinea:
   - `3–4` -> `Triventilklasse`;
   - `<3` -> `Quadriventilklasse`;
9. păstrează egalitățile fără tie-break inventat;
10. oprește-te înainte de `Triebformel`.

Aceasta este recapitularea legitimă a capitolului deoarece reorganizează mecanica într-un protocol aplicabil.

## 21. Limita clinică

O singură secțiune anti-inferențială, nu disclaimere repetate.

Capitolul nu autorizează transformarea:

- `Triebklasse` -> tip fix de personalitate;
- `Wurzelfaktor` -> genă demonstrată;
- `Triebgefahr` -> scor modern de risc;
- `Ventil` -> resursă sănătoasă;
- `Gefahrklasse` -> diagnostic;
- `Unterklasse +/−` -> bun/rău;
- prag `5/4` -> instrument psihometric modern.

Formula finală:

> **clasa organizează formal latențele unei serii; nu stabilește singură un diagnostic și nu fixează persoana într-un tip imuabil.**

## 22. Închidere spre cap. 43

Finalul trebuie să lase deschisă exact întrebarea următoare:

> **Dacă `Triebklasse` ne spune unde se află rădăcina dominantă și ce domenii funcționează ca pericol sau ventil, cum notăm într-o singură formulă relația dintre `Wurzelfaktoren` și `Symptomfaktoren`?**

Răspunsul aparține `Triebformel`, cap. 43.
