# GATE 10 — Vocea

Versiunea v3 are acum o densitate potrivită pentru deschiderea cărții:

- scena concretă apare înaintea doctrinei;
- termenii germani sunt introduși numai când rezolvă o problemă;
- avertismentele epistemice sunt integrate în argument, nu puse ca reguli administrative;
- paragrafele foarte scurte sunt rare și folosite pentru ritm;
- secțiunea genetică este suficientă pentru fidelitate, dar nu confiscă capitolul;
- Deri apare ca dezvoltare ulterioară și nu schimbă centrul de greutate;
- partea cea mai densă este corect secțiunea despre actul matur de alegere.

Vocea nu este nici de manual universitar inert, nici de popularizare. Ea poate susține o carte lungă dacă păstrăm variația de densitate între capitole.

# GATE 11 — Experiența cititorului

Capitolul produce o transformare clară:

`chip -> preferință -> Wahlhandlung -> problemă a alegerii -> Wahlsprache -> nevoie de gramatică -> model matur al alegerii -> limită -> Schicksal`

Cititorul nu primește încă o „cheie”, dar înțelege de ce va avea nevoie de una. Acesta este exact rolul capitolului.

Cele trei propoziții cu funcție de semnătură pot rămâne:

- **Fotografia este aceeași. Alegerea nu este.**
- **Alegerea precede interpretarea.**
- **Dacă alegerea este un limbaj, avem nevoie de o gramatică.**

Ele trebuie însă păstrate ca momente rare. Nu construim fiecare capitol în jurul a trei sloganuri similare.

Finalul funcționează: nu rezumă școlar, ci transformă problema alegerii în problema destinului și justifică apariția cap. 2.

# Ce nu mai trebuie făcut acum în capitolul 1

Nu mai adăugăm:

- descrierea celor 48 de imagini;
- cele opt categorii/factori;
- procedura completă de administrare;
- scorarea;

- o discuție contemporană despre validitatea testului;
- cazuri clinice ample.

Acestea ar fi semne de anxietate editorială, nu de completitudine.

Următorul pas este cercetarea 10/10 a capitolului 2 și construirea lui până la primul draft. După ce cap. 1–4 există în draft, Partea I se citește integral și se revine asupra fiecărui capitol pentru:
