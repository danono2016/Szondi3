# DEPRECAT — vechile gate-uri au fost simplificate

Acest fișier nu mai definește o succesiune obligatorie de 12 gate-uri.

Fluxul activ, criteriul de `STABLE DRAFT`, criteriul de `FINAL`, regula deep pass-ului și legea anti-perfecționismului se află în:

`docs/manual/MANUAL_FOUNDATION.md`

Principiul nou este deliberat mai simplu:

`întrebarea cititorului -> cercetare 10/10 -> bounded deep pass dacă este necesar -> arhitectură proprie -> DRAFT -> verificare doctrinară/formală -> reader pass -> continuity pass când există cluster -> STABLE DRAFT -> integrare finală -> FINAL`

Nu se deschide un nou pass fără o problemă numită.

Istoricul vechilor gate-uri rămâne în Git.
