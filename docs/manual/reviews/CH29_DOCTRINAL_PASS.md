## Calificările integrate și confirmate

### 1. `Urprojektion -> Partizipation`

Relația este păstrată pe două niveluri:

- `primäre / primordiale Projektion` este procesul pe baza căruia se constituie `Partizipation`;
- `Einssein`, `Gleichsein`, `Verwandtsein mit dem Objekt` descriu participația rezultată;
- formulările comprimate ale lui Szondi în care participația apare `als Urprojektion des Ichs` sunt păstrate fără a fuziona nivelurile.

### 2. `±p` și `projektive Inflation`

Nivelul testologic și construcția funcțională sunt separate corect:

- `±p` este ancora testologică a coactivării tendinței proiectiv-participative (`−p`) și a inflației (`+p`);
- în teoria Eului, această simultaneitate este tratată ca `projektive Inflation`;
- nu se formulează o echivalență brută între reacția factorială și construcția funcțională.

### 3. Proiecția secundară

Centrul doctrinar este acum formulat prin `Hinausverlegung der eigenen Seinsmacht des Ichs`.

După pierderea unității participative, propria `Seinsmacht` este din nou plasată asupra obiectului, în cadrul `Allodiastole ohne Partizipation`.
