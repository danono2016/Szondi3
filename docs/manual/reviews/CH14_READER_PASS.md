# Capitolul 14 — Reader pass autor–editor

**Capitol:** Încărcare cantitativă, Quantumspannung și profilul simbolic  
**Verdict:** PASS  
**Statut rezultat:** STABLE DRAFT

## Verdict de lectură

Capitolul funcționează ca închidere a Părții a III-a și nu cere rescriere înaintea progresiei. Distincțiile formale sunt lizibile, exemplele sunt suficient de concrete, iar finalul produce pragul pedagogic urmărit: cititorul știe să construiască un profil simbolic complet, dar încă nu îl interpretează.

Nu există o problemă numită care să justifice un nou pass.

## 1. `Vollreaktion ≠ Quantumspannung`

**PASS.**

Distincția devine intuitivă prin succesiunea:

- `3/1 → +` arată că totalul brut al alegerilor nu produce automat `!`;
- `3/3 → ±` arată că o Vollreaktion poate folosi toate cele șase fotografii fără Quantumspannung;
- `4/0 → +!` arată că Quantumspannung apare când acumularea trece de trei într-o singură direcție.

Textul nu cere o definiție suplimentară. Un adaos ar risca să repete ceea ce exemplele deja demonstrează.

## 2. `3/3 → ±` versus `4/2 → ±!`

**PASS.**

Perechea este bine aleasă. `3/3` separă totalul reacției de supraîncărcarea direcțională, iar `4/2` arată simultan că:

- reacția rămâne ambivalentă;
- cantitatea poate adăuga `!` fără să schimbe direcția de bază.

Acesta este sprijinul pedagogic principal al capitolului și nu are nevoie de încă un exemplu concurent.

## 3. Quantumspannung versus TspG

**PASS.**

Delimitarea este suficientă și bine dozată:

- Quantumspannung aparține reacției factoriale dintr-un profil;
- TspG aparține seriei;
- calculul TspG nu este predat aici.

Capitolul spune destul pentru a preveni confuzia terminologică fără să deschidă prematur aparatul Părții a VII-a.

## 4. Exemplul de profil complet

**PASS.**

Tabelul cu cei opt factori este util deoarece cititorul vede pentru prima dată întregul traseu formal într-un singur obiect. Exemplul nu este doar recapitulativ: face vizibil pragul dintre calcul și interpretare.

Secțiunea de reversibilitate (`d−!! → 0/5 → cardurile d`) este de păstrat. Ea fixează o idee care va deveni critică mai târziu: simbolul trebuie să rămână trasabil până la actele de alegere care l-au produs.

## 5. Ritm și dozaj

**PASS.**

Capitolul are o densitate potrivită pentru închiderea unei părți tehnice. Tabelele apar numai acolo unde sunt necesare, iar alternanța dintre regulă, caz-limită și consecință împiedică textul să devină o listă de distribuții.

Secțiunea despre dinamica `încărcare → ambivalență → descărcare` rămâne suficient de scurtă și este protejată prin anti-inferența explicită că un profil singular nu autorizează predicția unei succesiuni individuale.

## 6. Finalul Părții a III-a

**PASS.**

Finalul închide corect traseul:

`card → alegere → factor → frecvență → reacție → încărcare → profil simbolic`.

Ultima tensiune este fertilă și exactă: cititorul știe cum se produce `h+!`, dar nu știe încă ce problemă pulsională este numită prin `h`. Astfel, Partea a IV-a devine necesară fără ca factorul `h` să fie predat prematur.

## Decizie editorială

Capitolul 14 trece la **STABLE DRAFT** fără modificări de text.

Partea a III-a este, în acest punct, **STABLE DRAFT integral (cap. 10–14)**.
