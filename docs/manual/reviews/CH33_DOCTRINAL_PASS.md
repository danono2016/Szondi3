## Calificarea materială confirmată

Distincția `Tendenzspannung ≠ Quantumspannung` este acum formulată și integrată corect:

- `Tendenzspannung` = tensiunea dintre cele două tendințe opuse ale aceleiași trebuințe, vizibilă în special în reacția ambivalentă / bitendentă `±`;
- `Quantumspannung` = tensiunea cantitativă / supraîncărcarea predominantă într-o direcție, marcată prin semnele de încărcare;
- `±` și `!` nu codifică același fenomen;
- `Tendenzspannung` și `Quantumspannung` se pot întâlni în aceeași reacție.

## Achiziții doctrinare protejate

1. `Quantität` și `Tendenzrichtung` sunt coordonate distincte ale reacției factoriale.
2. `Leer-/Nullreaktion`, `Durchschnittsreaktion`, `Vollreaktion` rămân clase cantitative.
3. `0` indică mai întâi absența actuală a trebuinței din prim-plan, nu absența ei din persoană.
4. `Quantumspannung` nu înseamnă severitate clinică.
5. Schema `Quantumspannung -> Ambivalenz -> Entladung / Nullreaktion` rămâne model dinamic ce cere seria pentru observare, nu cronologie dedusă din profil unic.
6. Factorul partener rămâne pragul către cap. 34; metoda `Vektorbild` nu este predată aici.
