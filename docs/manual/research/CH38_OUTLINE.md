# CH38 — Outline consumabil

**Capitol:** 38 — De la profil la serie: de ce un singur profil nu este suficient  
**Statut:** OUTLINE COMPLETE  
**Bază:** `CH38_RESEARCH.md` — corpus pass 10/10 + bounded deep corpus pass.

## Întrebarea

De ce cere Szondi o serie dacă fiecare profil trebuie deja interpretat în întregimea lui?

## Teza

Un profil singular este un întreg testologic al unui moment și face vizibilă o `Schicksalsmöglichkeit`; seria leagă mai multe asemenea întreguri prin timp. Ea nu anulează profilul, ci permite să distingem ceea ce este actual sau episodic de ceea ce revine, persistă, alternează ori se transformă.

> **Seria nu caută „profilul adevărat”. Ea urmărește succesiunea posibilităților.**

## Mișcarea cognitivă

1. **Adâncimea nu este încă timpul.** Plecare directă din finalul cap. 37: complementul lărgește profilul, dar rămâne un moment.
2. **Un profil este complet pentru momentul lui.** *Lehrbuch*: un profil face vizibilă o `Schicksalsmöglichkeit`; fiecare profil din serie se citește separat, `in seiner Ganzheit`.
3. **Repetarea nu caută identitatea.** În doctrina lui Szondi, diferențele dintre profile pot exprima pluralitatea `Existenz- und Schicksalsmöglichkeiten`; seria urmărește `Wandlungsmöglichkeiten und -richtungen`. Aceasta rămâne doctrină istorică, nu demonstrație psihometrică modernă.
4. **Seria adaugă `Nacheinander`.** *Triebpathologie I* descrie succesiunea reacțiilor și reapariția configurațiilor. Formulă editorială: **profilul organizează simultaneitatea; seria adaugă succesiunea.**
5. **Două axe de lectură — explicația manualului.** Orizontal: fiecare profil ca întreg. Vertical: același factor/vector prin succesiunea profilelor. Nu prezentăm această schemă drept termen tehnic Szondi.
6. **Actual/episodic versus recurent/preferat.** *Lehrbuch*: profilul singular semnalează forme actuale/episodice; seria de 8–10 permite observarea formelor preferate/recurente.
7. **Seria nu este media profilelor.** Fiecare profil rămâne o posibilitate proprie; reacțiile rare nu sunt șterse prin majoritate; calculele seriale ulterioare au reguli separate.
8. **De ce 8–10.** Acesta este câmpul matur uzual la Szondi. Seriile mai scurte cer reguli formale speciale, tratate în cap. 40.
9. **Deri și Mélon — tradiție ulterioară.** Deri recomandă cel puțin șase, preferabil zece administrări; Mélon formulează zece administrări cu minimum 24 h. Nu fuzionăm aceste reguli cu procedura matură a lui Szondi.
10. **Final.** Odată profilul pus în timp, următoarea problemă este cum distingem constanța, schimbarea și faza — cap. 39.

## PROTECT doctrinar

- un profil = o `Schicksalsmöglichkeit`, nu totalitatea persoanei;
- fiecare profil se interpretează separat, `in seiner Ganzheit`;
- seria matură = de regulă 8–10 profile;
- profil singular = rang actual/episodic, nu nul metodologic;
- seria adaugă succesiunea și permite observarea formelor recurente/preferate;
- variabilitatea nu este automat eroare în doctrina lui Szondi;
- această teză nu devine validare psihometrică modernă;
- seria nu este media profilelor;
- reacția rară nu este anulată prin majoritate;
- schema orizontal/vertical este explicația manualului;
- constanță/schimbare/fază rămân cap. 39;
- seria scurtă și `Tabelle 13` rămân cap. 40;
- calculele seriei rămân cap. 41+;
- Deri/Mélon rămân tradiție ulterioară explicit atribuită.
