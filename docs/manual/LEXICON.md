# Manualul Szondi — Lexicon editorial viu

**Statut:** LIVING DOCUMENT  
**Scop:** stabilizarea traducerilor și a deciziilor terminologice pe măsură ce capitolele sunt cercetate.  
**Regulă:** un termen nu este „rezolvat” doar pentru că există o traducere plauzibilă. Se urmăresc sensul doctrinar, cronologia și consecvența între capitole.

---

# Convenții

Stări posibile:

- **STABIL** — traducerea poate fi folosită consecvent;
- **STABIL CU GERMANĂ LA PRIMA APARIȚIE** — traducerea română este suficientă după definire;
- **CONTEXTUAL** — termenul cere traduceri diferite după context;
- **NEREZOLVAT** — nu se introduce liber în proză înainte de control dedicat.

# Regula de lucru

Orice cercetare de capitol care întâlnește un termen nou sau modifică sensul unuia existent trebuie să actualizeze acest document înainte de draft, dacă termenul afectează mai mult de un capitol.
