## Control doctrinar

### `Instinkt / Trieb` — PASS

Textul nu prezintă distincția complet/incomplet ca definiție universală și nici ca descoperire exclusivă a lui Szondi. Formula este atribuită psihologiei animale, în special lui Ziegler, și este prezentată ca distincție adoptată de Szondi. Textul evită eroarea animal = instinct / om = pulsiune și păstrează caracterul gradual al completitudinii, adaptării și individualizării.

### `Bedürfnis` — PASS

Sunt separate:

- sensul biologic general de trebuință;
- sensul tehnic `Triebbedürfnis = Triebfaktor`.

Textul spune explicit că trebuințele/factorii „nu sunt încă pulsiuni” și previne confundarea celor opt factori cu opt `Triebe`.

### `Tendenz / Strebung` — PASS

DRAFT-ul nu inventează două trepte. Formula `Triebstrebung = Triebtendenz` este expusă central. Diferența românească „tendință / năzuință” este tratată ca diferență lexicală, iar riscul ca „năzuință” să sugereze proiect conștient este explicit controlat.

### Ierarhia — PASS

Ierarhia este exactă la nivelul necesar cap. 5:

`2 tendințe/năzuințe -> 1 trebuință/factor`  
`2 trebuințe/factori -> 1 pulsiune/vector`

Textul păstrează ideea szondiană că `Trieb` este deja o sinteză / `Verschränkung` și nu unitatea elementară.

### Atribuirea Freud / Häberlin / Ziegler — PASS

- Ziegler: complet/incomplet;
- Häberlin: `Tendenz` ca direcție;
- Freud: interlocutor pentru teoria generală a pulsiunii, nu sursa taxonomiei Szondi.

Nu apare o fuziune tacită a vocilor.

### Deri / Mélon — PASS

Deri și Mélon sunt prezentați ca tradiție ulterioară. DRAFT-ul folosește Deri pentru a arăta posibila estompare need/drive și Mélon pentru schema pedagogică 4/8/16, fără a le folosi pentru a corecta sursa primară.

### Prematuritate — PASS

Capitolul nu predă conținutul celor opt factori, semnele de reacție, administrarea sau interpretarea. Menționează numai arhitectura numerică strict necesară pentru a face necesar cap. 6.
