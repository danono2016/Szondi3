2. `Leer-/Nullreaktion`, `Durchschnittsreaktion`, `Vollreaktion` rămân clase cantitative.
3. `Tendenzspannung` și `Quantumspannung` rămân distincte și pot coexista în aceeași reacție.

5. `Quantumspannung` / `!` nu indică severitate clinică.
6. Dinamica `Quantumspannung -> Ambivalenz -> Entladung / Nullreaktion` nu este inferată dintr-un profil singular; seria rămâne necesară pentru observarea succesiunii.
