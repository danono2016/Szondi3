## Verificări

- Procedura principală urmează `Lehrbuch` și `Triebpathologie I`, nu o sinteză hibridă a tradițiilor.
- Prima alegere este descrisă serie cu serie: 2 simpatice + 2 antipatice din fiecare serie de 8.
- VGP este introdus procedural ca profil rezultat din Grundversuch; nu este echivalat cu conștientul, masca sau personalitatea manifestă.
- Nachwahl este descrisă asupra celor 24 de fotografii rămase, păstrând reexpunerea serie cu serie.
- EKP este separat de VGP și ThKP.
- Este introdusă limita matură din `Lehrbuch`: dependența numerică a EKP de distribuția produsă de VGP (`numerischer Wahlzwang`).
- EKP nu este prezentat ca profil independent complet și nici ca „adevăratul sine ascuns”.
- Deri este atribuită explicit pentru `final choice` și pentru reformularea practică a instrucțiunii; aceste elemente nu sunt retroproiectate în Szondi.
- Mélon este atribuit explicit ca tradiție pedagogică ulterioară.
- Nu sunt introduse semnele +/−/±/0, Quantumspannung sau interpretarea complementară din cap. 37.
