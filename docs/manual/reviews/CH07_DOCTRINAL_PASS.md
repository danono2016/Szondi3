# Capitolul 7 — Doctrinal pass

**Capitol:** Factorul pulsional ca „radical”  
**Text verificat:** DRAFT v1  
**Rezultat:** DOCTRINAL PASS / AUTHOR READER PASS PENDING

## Probleme controlate

### 1. `Radikal` este termen primar legitim

PASS. `Triebpathologie I` are explicit `Triebfaktoren als «Radikale»`, `biologische Radikale` și examinarea `Radikalnatur der acht Triebfaktoren`. `Lehrbuch` formulează direct `Triebe sind Radikale`, `Triebradikale oder Triebfaktoren` și `Triebfaktoren sind die Radikale des Trieblebens`.

DRAFT-ul nu prezintă `radical` ca invenție a manualului.

### 2. Trecerea patologic -> fiziologic/general

PASS cu limită explicită. Textul descrie traseul lui Szondi `psychopathologische Erbkreise -> Urtriebgene -> physiologische Triebbedürfnisse/Triebfaktoren` ca ipoteză doctrinară istorică și spune explicit că nu este genetică contemporană validată.

### 3. `Schicksalsmöglichkeiten`

PASS. DRAFT-ul folosește numai registrele necesare pentru teză — dezvoltare, caracter, profesie/social, cultură, patologie — fără inventarul factor cu factor. Nu invadează cap. 15–26.

### 4. `Wurzelfaktor`

PASS. Termenul este dezambiguizat și separat de `Triebradikal`; nu este predat formal. Deri/Mélon sunt invocați numai pentru traducerea tradiției testologice `root factor / facteur-racine`.

### 5. Deri / Mélon / manual

PASS. Teza despre radical este construită din Szondi. Explicația `radicalul este numele dat continuității...` este declarată explicit ca formulare a manualului.

### 6. Frontiera cu capitolele următoare

PASS. Textul nu predă notația reacțiilor, clasele, `Wurzelfaktor`, manifest/latent sau psihologia completă a factorilor. Finalul deschide numai problema bipolarității și a contrariilor pentru cap. 8.

## Observație pentru reader pass

Singura întrebare rămasă este de ritm: secțiunile despre originile clinice, radicale și limite trebuie citite ca proză continuă pentru a vedea dacă apar redundanțe între ideile „boala nu e definiția” / „radicalul nu e diagnostic”. Aceasta este o problemă de reader pass, nu doctrinară.

## Verdict

**DOCTRINAL PASS.** Nu există o problemă materială care să ceară cercetare suplimentară sau rescriere doctrinară. Capitolul poate intra în lectura autor–editor.
