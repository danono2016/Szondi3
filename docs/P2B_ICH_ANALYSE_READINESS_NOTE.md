## 1. IA-A core already source-verified

### `DR_SZ_IA_1956_A_000040` — Egodiastole / Egosystole

Source-local doctrine states:

- Egodiastole = Ich-Ausdehnung and maps to p-Funktion;
- Egosystole = Ich-Einengung and maps to k-Funktion;
- this opposed functional activity underlies all Ich-Funktionen and determines all Ich-Stadien.

This is a better P2B foundation for p/k Ego semantics than inferring the polarity from isolated Lehrbuch labels.

### `DR_SZ_IA_1956_A_000043` — four elementary Ego functions and signs

PDF-arbitrated source-local mapping:

- `-p` = Projektion -> Einssein/Gleichsein/Partizipationsdrang;
- `+p` = Inflation -> Verdoppelung/Vollkommenheit/Allessein;
- `+k` = Introjektion -> Einverleibung/Inbesitznahme/Alleshaben;
- `-k` = Negation -> Verzichten/Verneinen/Verdrängen, with Desimagination/Destruktion as extreme end-direction in the source formulation.

The signs are PDF-arbitrated because canonical OCR corrupts `+p` and `+k`.

### `DR_SZ_IA_1956_A_000049` — Negation is broader than repression

This is a high-priority anti-inference candidate:

- Negation is a primordial Elementarfunktion / Ich-Radikal;
- Verdrängung is a **Unterform** of Negation, not the synonymous or superordinate category;
- the common testological marker of the Negation family is `-k`;
- concrete forms depend on p phase and quantity/intensity of negation.

Therefore a future rule `-k -> repression` would be source-distorting. At most, repression is one specifically conditioned form inside the broader Negation family.

### `DR_SZ_IA_1956_A_000050` — ordered developmental sequence

The four elementary functions are reused as developmental stages:

1. projektive Partizipation;
2. Inflation / Allessein;
3. Introjektion / Haben-Alleshaben;
4. Negation / Verzichten-Verneinen / adaptation.

This is an interpretive/developmental structure, not a license to infer chronological developmental level from one Sch reaction without a source-grounded discriminator.

### `DR_SZ_IA_1956_A_000051` — Integration / Desintegration

PDF arbitration establishes:

- `integriertes Ich = Sch ± ±`;
- `Desintegration = Sch 0 0`;
- source frames full Verschränkung of all four Ich-Radikale as an ideal and warns that any Ich-Unifunktion may become dangerous.

P2B caution:

- the testological image `Sch ±±` may be named according to the source as integrated Ego configuration;
- software must not silently upgrade the configuration into proof that an individual has achieved all existential, moral, spiritual, or developmental consequences attached to the source's idealized discussion.
