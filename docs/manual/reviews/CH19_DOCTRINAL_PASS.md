# Capitolul 19 — Doctrinal pass

**Capitol:** Factorul hy — a se arăta și a se ascunde: exhibare, rușine și bariera morală  
**Verdict:** PASS  
**Statut rezultat:** DRAFT v1 / reader pass pending

## Verificări centrale

1. `hy` nu este prezentat ca factor al isteriei, ci prin polaritatea matură `Sich-zur-Schau-Tragen / Sich-Verbergen-Sich-Verstecken`.
2. `+hy` păstrează `Geltungsdrang` și direcția manifestării; exhibiționismul și isteria apar numai ca forme istorice/extreme, nu ca definiție automată.
3. `−hy` păstrează ascunderea, `Schamhaftigkeit` și `Scham- und Ekelschranke`; textul spune explicit că ascunderea afectului nu înseamnă absența lui.
4. `±hy` este redat prin `moralischer Zwiespalt und Zweifel`, nu prin indecizie banală.
5. `0hy` este tratat conform regulii generale a Nullreaktion din `Lehrbuch`: lipsă actuală din prim-plan cu mai multe posibilități de satisfacere/descărcare și numai rar slăbiciune constitutivă. Nu este redus la o singură poveste.
6. Diferența `etic (e)` versus `moral (hy)` este păstrată fără a transforma factorul `hy` într-o măsură a moralității persoanei.
7. Überdruck rămâne mai întâi informație cantitativă; formele clinice severe nu devin diagnostic sau scor de severitate.
8. Deri este folosită atribuit pentru diferența intensitatea afectului / vizibilitatea afectului.
9. Mélon este folosit atribuit pentru aprobarea versus șocarea opiniei, bariera emoțională și pluralitatea lui `hy0`; formulările lui nu sunt retroproiectate în Szondi.
10. Relația completă `e–hy` și cele 16 imagini ale vectorului P sunt păstrate pentru cap. 20.

## Riscuri controlate

- „Factor moral” poate suna ca scor de virtute; DRAFT-ul corectează explicit această lectură.
- `hy+` poate invita la diagnosticul de isterie/exhibiționism; textul îl interzice explicit.
- `hy−` poate invita la echivalarea cu introversia sau lipsa afectelor; textul separă vizibilitatea de intensitatea afectivă.
- `hy0` este doctrinar polisemic; DRAFT-ul nu inventează o semnificație unică.

## Verdict

DRAFT-ul este doctrinar coerent cu `Lehrbuch` și `Triebpathologie I`, controlat cu `Schicksalsanalyse`, Deri și Mélon și delimitat suficient de materialul vectorial/clinic ulterior.
