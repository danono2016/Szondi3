# Capitolul 21 — Doctrinal pass

**Capitol:** Factorul k — Egosystole: introiecție și negație  
**Verdict:** PASS  
**Statut rezultat:** DRAFT v1 / reader pass pending

## Verificări centrale

1. `k` este prezentat prin formularea matură `Egosystole / Ich-Einengung`, nu redus la originea sa katatonică.
2. Esența factorului este păstrată ca `bejahende bzw. verneinende Stellungnahme`.
3. `+k` este redat prin `Introjektion / Einverleibung / Inbesitznahme / Kapitalisierung` și prin formula `Radikal des Habens`.
4. `Haben` este explicat mai larg decât posesia materială: interese, cunoaștere, valori, caracter, profesie, incorporare psihică.
5. Formula `Die Introjektion ist die Brücke des Ichs zur Wahrnehmung der äußeren und inneren Welt` este păstrată în sensul ei doctrinar și nu folosită pentru a patologiza `+k`.
6. `−k` este redat prin `Negation / Verneinung / Neinsagen`; diferența față de `Verneinung` freudiană este explicită.
7. Destinele extreme ale lui `−k` (`Negativismus`, destrucție) nu sunt confundate cu definiția reacției medii.
8. `k−` este separat de `s+`: negarea egologică nu este echivalată cu agresiunea/Thanatosul.
9. `k±` este descris ca `Intronegation`, simultaneitatea Introjektion + Negation; relația istorică cu `Zwang` nu devine diagnostic automat.
10. `k0` este tratat ca diminuare/suspendare actuală și relativă a `Stellungnahme` egosistolice și nu ca „absență a Eului”.
11. Dependența interpretativă față de `p` este explicită; capitolul nu anticipează sistemul complet Sch.
12. Formula pedagogică „Eul se delimitează atât prin ceea ce face al său, cât și prin ceea ce refuză” este marcată explicit ca explicație a manualului, nu ca citat Szondi.
13. Teoria completă a celor patru funcții ale Eului, `Pontifex oppositorum`, autonomia Eului, `Ich-Schicksal` și integrarea rămân rezervate cap. 27–31.

## Riscuri controlate

- `Egosystole` nu este tradusă ca simplă inhibiție sau introversie.
- `+k` nu devine egoism/narcisism automat.
- `−k` nu devine negativism catatonic automat.
- `Haben` nu este redus la posesia materială.
- originea clinică nu este prezentată ca validare genetică actuală.
- vocabularul istoric `Dur-Ich` este menționat numai marginal și contextualizat.

## Verdict

DRAFT-ul este coerent cu `Lehrbuch`, controlat prin `Ich-Analyse` și celelalte surse canonice, păstrează vocabularul szondian relevant și respectă frontiera arhitecturală față de teoria completă a Eului.
