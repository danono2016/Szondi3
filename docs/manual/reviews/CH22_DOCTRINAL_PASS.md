# Capitolul 22 — Doctrinal pass

**Capitol:** Factorul p — Egodiastole: participare, proiecție și inflație  
**Verdict:** PASS  
**Statut rezultat:** DRAFT v1 / reader pass pending

## Verificări centrale

1. `p` nu este prezentat ca „factor al paranoiei”; originea clinică este separată de definiția matură `Egodiastole / Ich-Erweiterung / Erweiterer der Existenz`.
2. Definiția de bază urmează `Lehrbuch`: `Drang zur Erweiterung, zur Diastole des Daseinsraums`.
3. Distincția `Allodiastole` versus Egodiastole propriu-zisă este păstrată: `Partizipation/Projektion` versus `Inflation`.
4. `−p` nu este redus la mecanismul defensiv freudian; sunt păstrate `Urprojektion / Partizipation`, proiecția secundară și `Hinausverlegung`.
5. `+p` este definit prin `Inflation / Alles-Sein / Beides-Sein / Verdoppelung`, nu prin vanitate sau „ego mare”.
6. Afirmația lui Szondi că reacția pozitivă medie nu este automat patologică este păstrată; megalomania și formele paranoide rămân extreme/destine clinice.
7. `p±` este simultaneitatea `Projektion + Inflation`, nu o medie între ele.
8. `p0` este redat prin `Räumung der Triebregungen aus dem Wunschbewußtsein` și este explicit dependent de k; nu este lipsă de dorință sau lipsă de Eu.
9. `Sein / Existenzkraft / Seinsmacht / Potestas` sunt atribuite teoriei lui Szondi și nu prezentate ca entități psihologice contemporane validate.
10. Diferența față de `hy` și față de funcțiile de contact este explicită, pentru a preveni dizolvarea factorului într-un vocabular generic al relațiilor.
11. Deri este folosită numai atribuit pentru caracterul larg al proiecției; Mélon numai ca tradiție secundară pentru p−/p+ și Être. Niciunul nu rescrie vocabularul primar.
12. Teoria completă a celor patru Elementarfunktionen, integrarea Eului și Pontifex oppositorum rămân pentru cap. 27–31; relația completă k–p rămâne pentru cap. 23.

## Verificarea punctului vulnerabil

Punctul cel mai ușor de falsificat era întrebarea: de ce `−p` și `+p` aparțin amândouă Egodiastolei?

DRAFT-ul păstrează distincția lui Szondi:

- la `−p`, existența se extinde prin obiect / mediu (`Allodiastole`, Partizipation, Projektion);
- la `+p`, propria existență a Eului se dilată (`Inflation`, Alles-Sein).

Formula manualului „cât de departe se poate întinde existența mea?” este marcată ca explicație pedagogică, nu ca definiție textuală.

## Riscuri controlate

- `p− = paranoid` — interzis explicit;
- `p+ = grandios/narcisic` — interzis explicit;
- `Projektion = doar Freud` — delimitat;
- `Inflation = limbaj cotidian` — delimitat;
- `Partizipation = atașament/empatie` — evitat;
- `Sein` transformat prematur în filozofie generală — amânat;
- p citit fără k — interzis explicit.
