# CH33 — Outline consumabil

**Titlu:** Lectura reacției factoriale: sens, încărcare și context  
**Statut:** OUTLINE COMPLETE

## Problema cognitivă

Cap. 32 a schimbat întrebarea din „ce înseamnă semnul?” în „ce face reacția aici?”. Cap. 33 trebuie să arate **ce este de fapt reacția pe care urmează s-o punem în context**.

Cititorul vede `+k`, `−p`, `±m`, `0e`, eventual cu `!`, și riscă să creadă că simbolul este o unitate simplă. Szondi îl construiește însă din două coordonate: **cantitatea alegerii** și **direcția tendinței**.

## Mișcarea capitolului

### 1. Simbolul este o condensare

Pornire de la un fapt vizual: două reacții pot avea același `+`, dar una poate fi medie și alta puternic încărcată. Semnul de direcție nu spune tot ce s-a întâmplat în alegere.

Introduce formula matură din `Lehrbuch`: fiecare act de alegere se evaluează după `Quantität` și `Tendenzrichtung`.

### 2. Cantitatea: gol, mediu, plin

Prezintă cele trei clase:

- `Leer-/Nullreaktion`;
- `Durchschnittsreaktion`;
- `Vollreaktion`.

Nu reface cotarea din cap. 13–14. Acum întrebarea este interpretativă: ce fel de stare dinamică indică fiecare categorie?

### 3. Reacția medie — categoria uitată

Accent special: între gol și supraîncărcare există `Durchschnittsreaktion`. În general, trebuința este cantitativ disponibilă/pregătită pentru satisfacere. Nu este însă „normalitate psihologică” și nu devine sens autonom.

Aici apare prima fisură: chiar Szondi spune că reacția medie poate căpăta altă greutate când partenerul este gol sau raportul factorilor este polarizat. Nu interpretăm încă vectorul; doar vedem de ce cantitatea nu ajunge singură.

### 4. Direcția: afirmare, negare, bitendență

`+` / `−` / `±` ca `Stellungnahme` față de tendință.

Protecție:

- `+` nu este „bine”;
- `−` nu este „rău”;
- `±` nu este medie sau integrare.

Dar nu repeta anti-inferențele cap. 32; spune-le o dată, prin termenii lui Szondi.

### 5. `Quantumspannung`

Încărcarea nu este decor și nici severitate clinică. Ea arată presiunea cantitativă a factorului. Păstrează termenii `Überdruck / Hypertonie der Bejahung` și corespondentul negativ acolo unde sunt utili.

Distinge reacția plină ambivalentă: ambivalența și încărcarea pot coexista.

### 6. `0`: ceea ce lipsește acum

Formula centrală: `0` spune mai întâi că trebuința lipsește **actual din prim-plan**, nu că lipsește din persoană.

Prezintă compact posibilitățile primare: satisfacere/manifestare, satisfacere pe căi de socializare/sublimare, rar slăbiciune constituțională.

Nu transforma lista în dicționar. Tocmai pluralitatea sensurilor face necesar profilul și seria.

### 7. Reacția ca moment dintr-o mișcare

Introduce modelul Szondi:

`Quantumspannung → Ambivalenz → Entladung / Nullreaktion`.

Imediat califică: este o dinamică ce poate deveni vizibilă în serie; profilul unic nu demonstrează că persoana a parcurs aceste faze.

Aceasta pregătește cap. 38 fără să consume seria.

### 8. Pragul către vector

O reacție complet citită are acum:

- factorul căruia îi aparține;
- direcția;
- cantitatea/încărcarea;
- statutul dinamic actual.

Dar încă nu are sensul ei relațional complet. `Lehrbuch` spune explicit că interpretarea factorului depinde de constelația partenerului.

Încheiere organică: abia când două reacții se întâlnesc apare `Vektorbild`. Acolo începe cap. 34.

## Ton

Metodic, dens, fără exces de balustrade. Lasă termenii `Quantität`, `Tendenzrichtung`, `Durchschnittsreaktion`, `Vollreaktion`, `Quantumspannung`, `Bitendenz` să poarte argumentul.

## Frontiere protejate

- reacția ≠ trăsătură;
- intensitatea ≠ gravitate clinică;
- `0` ≠ absența trebuinței din persoană;
- `±` ≠ armonie;
- modelul dinamic ≠ cronologie demonstrată din profil unic;
- factorul partener este numit, nu interpretat vectorial;
- nicio clinică.
