# Audit transversal canonic — capitolele 1–34

**Statut:** IN PROGRESS  
**Rol:** audit științific/doctrinar, nu reader pass stilistic  
**Corpus canonic:** cele 8 volume Szondi + Susan Deri + Jean Mélon  
**Regulă de probă:** documentele `research/` sunt numai hartă de căutare. Un verdict transversal se închide numai după confruntarea directă cu sursele canonice relevante.

## Scop

Auditul nu repetă doar verdictul local al fiecărui capitol. Urmărește dacă aceeași noțiune este folosită consecvent în toate locurile în care reapare și dacă manuscrisul respectă simultan:

1. definiția canonică;
2. nivelul conceptual (tendință / factor / vector / reacție / Vektorbild / profil / serie / clinică);
3. cronologia doctrinară;
4. atribuirea Szondi / Deri / Mélon;
5. procedura experimentală;
6. continuitatea dintre capitole;
7. tezele transversale care își schimbă rangul când sunt privite la nivelul întregului sistem.

## Axe de audit

### A. Arhitectura pulsională și terminologia fundamentală

Capitole principale: 5–9, cu recurențe în 15–34.

Se verifică transversal:

- `Triebstrebung = Triebtendenz`;
- `Triebbedürfnis = Triebfaktor`;
- două tendințe / năzuințe constituie o trebuință / factor;
- două trebuințe / factori se leagă (`Verschränkung`) într-un `Trieb / Triebvektor`;
- bipolaritatea factorială versus polaritatea vectorială;
- `Triebradikal / Triebfaktor / Wurzelfaktor` și polisemia tehnică ulterioară a lui `Wurzelfaktor`.

**Stare:** CONTROL DIRECT ÎN CURS. Reparația cap. 7 a fost confirmată direct în `Lehrbuch`: Szondi folosește generic `Wurzelfaktor` pentru radical și, ulterior, specializat în aparatul `Triebformel` în opoziție cu `Symptomfaktor`.

### B. Nomenclatura celor patru vectori și opt factori

Capitole principale: 6, 15–26, cu recurențe în 32–34.

Se verifică:

- S = Sexualtrieb, h/s;
- P = Paroxysmaltrieb / Überraschungstrieb, e/hy;
- Sch = Ichtrieb, k/p;
- C = Kontakttrieb, d/m;
- atribuirea exactă a denumirilor și absența retroproiecțiilor Mélon/Deri.

**Stare:** CONTROL DIRECT ÎN CURS. Corecția cap. 6 este confirmată: `Überraschungstrieb` este termen folosit explicit de Szondi; cap. 20 este aliniat.

### C. Administrare, VGP, EKP, ThKP și transcriere factorială

Capitole principale: 10–14; recurențe în 32–34 și capitolele viitoare despre complement.

Se verifică:

- materialul: 48 fotografii, 6 serii × 8 factori;
- `Instruktion Nr. I` — expunere simultană, 2 simpatice + 2 antipatice;
- `Instruktion Nr. II` — `Nachwahl`: dintre cele 4 rămase se aleg cele 2 relativ antipatice; celelalte 2 sunt relativ simpatice;
- separarea VGP / EKP / ThKP;
- `numerischer Wahlzwang` al EKP;
- transcrierea separată a VGP și EKP;
- Tabelle 3, reacțiile factoriale și încărcările.

**Stare:** CONTROL DIRECT EFECTUAT pentru continuitatea 10–14. Cap. 11 a fost corectat după `Instruktion Nr. I/II`; varianta necanonică introdusă anterior pentru inversarea `Nachwahl` a fost eliminată. Cap. 12 a fost aliniat explicit pentru transcriere separată VGP/EKP.

4. **Cap. 12:** continuitatea cu EKP era implicită — clarificată: VGP și EKP se transcriu separat.
