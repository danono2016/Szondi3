# CH38 — Doctrinal audit

**Capitol:** 38 — De la profil la serie: de ce un singur profil nu este suficient  
**Status:** PASS WITH ONE MATERIAL ADDITION + TWO QUALIFICATIONS / INTEGRATED / SCIENTIFIC RECHECK REQUIRED

## Primul audit științific extern

DRAFT v1 a fost confruntat direct cu sursele canonice relevante, în special *Lehrbuch*, *Triebpathologie I*, Deri și Mélon, cu control separat pentru profil singular / serie, `Nacheinander`, numărul profilelor și drepturile interpretative care apar numai odată cu seria.

Nucleul a fost confirmat:

- profil singular ≠ serie;
- fiecare profil trebuie citit `in seiner Ganzheit`;
- un profil face vizibilă o `Schicksalsmöglichkeit`, nu totalitatea posibilităților persoanei;
- seria adaugă `Nacheinander` și permite observarea recurenței și a transformării;
- variabilitatea serială are rang doctrinar în sistemul lui Szondi, fără a constitui prin ea însăși validare psihometrică modernă;
- Deri și Mélon sunt corect păstrați ca tradiție ulterioară explicit atribuită;
- seria nu este o medie a profilelor.

Verdictul extern:

**PASS WITH ONE MATERIAL ADDITION + TWO QUALIFICATIONS. Nu încă DOCTRINAL PASS.**

## Intervenții integrate în DRAFT v2

### 1. MATERIAL ADDITION — funcțiile diferite ale numerelor seriei

DRAFT v1 comprima prea mult prin formula generală „8–10 profile”. DRAFT v2 separă acum trei niveluri canonice:

1. scopul general al `Serienuntersuchungen` / surprinderea `Existenzmöglichkeiten`: **mai multe profile, `möglichst 10`**;
2. anumite proceduri interpretative, inclusiv cele deja întâlnite în `Komplementmethode` și lectura formelor preferate de `Triebgefahr / Abwehr`: **8–10 profile**;
3. formalizările `Trieblinnäus`: reguli proprii pentru **3–9 profile**; la **opt profile**, Szondi formulează `Konstanz des gesamten Trieblinnäus`; seriile scurte sunt raportate prin `Tabelle 13` la baza de zece.

Protecție: **8–10 nu este o regulă universală pentru toate metodele seriale.**

### 2. QUALIFY — `in seiner Ganzheit` fără „complet” exhaustiv

Formula din v1 „profilul singular este complet ca profil al momentului său” a fost înlocuită cu:

**„Profilul singular trebuie citit ca un întreg în momentul său; nu este suficient pentru dinamica serială.”**

Astfel se păstrează exigența `in seiner Ganzheit` fără a sugera că profilul singular ar cuprinde toate posibilitățile actuale sau toate nivelurile dinamice.

### 3. QUALIFY ATTRIBUTION — aparițiile rare

DRAFT v1 spunea prea tare că „Szondi avertizează” asupra reacției rare. Auditul nu a identificat o maximă primară explicită formulată astfel.

DRAFT v2 păstrează numai ceea ce susține practica interpretativă canonică:

**o apariție rară nu este eliminată automat numai fiindcă este minoritară în serie.**

Aceasta este prezentată ca rezultat al practicii interpretative a lui Szondi, nu ca citat sau regulă textuală universală.

## Achiziții doctrinare protejate pentru reverificare

- un profil = o `Schicksalsmöglichkeit`;
- fiecare profil se citește `in seiner Ganzheit`, fără echivalarea cu exhaustivitatea;
- scopul general al seriei: `mehrere, möglichst 10`;
- 8–10 = interval al unor proceduri, nu prag universal;
- reguli distincte `Trieblinnäus` pentru 3–9 profile;
- la opt profile: `Konstanz des gesamten Trieblinnäus`;
- `Tabelle 13` raportează seriile scurte la baza de zece;
- profil singular = actual / episodic; seria permite forme recurente / preferate;
- seria introduce `Nacheinander`;
- variabilitatea nu este automat eroare în doctrina lui Szondi, fără a deveni validare psihometrică modernă;
- seria nu este media profilelor;
- aparițiile rare pot rămâne relevante în practica interpretativă, fără atribuirea unei maxime textuale neidentificate;
- schema orizontal / vertical este explicația manualului;
- Deri și Mélon rămân tradiție ulterioară explicit atribuită.

## Următorul control

**Reverificare științifică externă a DRAFT v2**, cu atenție specială la cifrele **3–10**, la diferența dintre `mehrere, möglichst 10`, utilizările 8–10 și regulile `Trieblinnäus`, precum și la coerența frontierelor cu cap. 39–40.
